# career

Domain knowledge entries for **career and job-search** work: positioning, opportunity evaluation,
application materials, and pipeline operations. Operational how-to lives in
[[job-search-strategist]] and its spokes; this folder holds what we have learned applying it.

**Personal context only** (`personal-solo`). Company-named research, comp figures, and application
drafts do not belong in tracked workspace files: keep those in `07-projects/` (gitignored) or
`05-artifacts/`. See [[08-knowledge/_README]] for conventions.
