## For future agent

- **TL;DR:** The vault already **corrects** (independent detectors, CI, `vqa calibrate`) and partly **heals** (rebuilds, nightly fold). It did not **improve** through ordinary sessions except the visual ledger and close-out detector mint. `/optimize` and `/health` were Claude-only and sign-off-gated, so P0 broken edges waited on Sean. ## Decision rule before minting

If adding X does not change what the next cold agent on another device will load, find, or prove, do not mint. That is [[experiment-validity-baseline]] applied to the vault.

## Transfer, not clone

A process on hub A (order of operations, done-gate, interrupt) may apply to cluster B after modification. Photoreal/#12 is the **attach template** — copy the *shape*, not the GPU toolkit. Corollary access is a reciprocal `related` + knowledge-hint + one Layer-0 key, not a duplicate skill.

## Sign-off vs independent push

**Push without waiting** (`personal-solo`): mechanical P0 heals; calibrated detector mint; corollary edges; knowledge from a real miss; a spoke that extends an existing hub.

**Still sign-off:** archive, rename, shrinking consolidation, new foundation, new numbered framework (3+ consumers + fetch the next integer), employer repos, leave-the-building.
