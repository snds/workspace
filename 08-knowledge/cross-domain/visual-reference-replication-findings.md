# For future agent

**TL;DR:** Faithful LCARS is the hard exam for a **system-agnostic** recreation pipeline (Construction IR → Scene IR → prove). Concept + context + intent + aesthetic all count. Pixel vibe-match without programmatic emission fails the program. Agents fail when they use VLM prose as measurement, accept Spirit as Literal, code before IR, or treat tests-green as visual done.

**Key claims (as of 2026-08):**

1. LCARS pack proves the method; the method must transfer to other system packs.
2. Existing visual QA skills are insufficient unless they are the **done-gate**.
3. Literal recreation requires measured Construction IR before React/CSS, then distillation into IR-driven catalog primitives.
4. Secondary constraints must not silently override northstar samples.
