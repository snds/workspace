# Self-improve — correct, heal, then leave the vault better

One home for vault evolution through **normal use** across surfaces, agents, and
devices. Command hubs and session-end **invoke** this; they do not copy it.

Doctrine homes: [[agentic-error-correction-foundations]] (independent refuse) ·
[[08-workspace-contribution-framework]] (where a write belongs) · [[close-out]]
(QA detector mint) · [[11-anticipatory-failure-analysis]] (ledger from real
misses) · [[experiment-validity-baseline]] (decision rule before minting).

Git is the sync. A mint that is not committed here does not exist on the other
machine. Never employer (`c8/*`). Never a parallel brain.

## Three modes (run only the ones this session evidenced)

1. **Correct** — an independent detector already exists. Run it. Refuse false
   `done`. Same-model critique is polish. Home: [[close-out]] steps 1–3, #06,
   validators, `vqa calibrate`.
2. **Heal** — connective tissue is broken: dangling wikilink, empty hub
   triggers, registry drift, reciprocity hole, Layer-0 under-fire on a real
   utterance, silent skip. Fix the **smallest edge**. Rebuild
   (`build-related.py` → `build-registry.py` → `build-trigger-routes.py` →
   validators). Push. Do not wait for Sean on mechanical P0.
3. **Improve** — the next cold agent would miss what this session learned.
   Mint the smallest layer, wire corollary access, push.

`/optimize` remains the periodic seven-surface audit. `/health` remains
epistemic hygiene. Nightly remains opt-in fold/rebuild. This skill is the
**per-session** path so those jobs are not the only time the vault moves.

## Improve classes (smallest first)

Write the decision rule before minting: *If I add X, the next cold agent on
another device will load / find / prove Y.* If adding vs not-adding does not
change that, do not mint ([[experiment-validity-baseline]]).

| Class | Mint | Do not |
|---|---|---|
| **Corollary access** | `related`, knowledge-hint, one Layer-0 key, routing fixture | A new file whose only job is a link |
| **Transfer** | Adapt the *process* (order, done-gate, interrupt) from hub A to cluster B | Clone the toolkit / GPU / scripts (photoreal/#12 is the attach template) |
| **Detector** | [[close-out]] capability mint + planted fixture | VLM "looks good" as a skill |
| **Knowledge** | `08-knowledge/` + `_INDEX` from a real miss | How-to that belongs in a skill |
| **Research** | Survey into knowledge, then decide | Invent a hub from training-set vibes; fetch before the next framework integer |
| **Spoke** | `00-bootstrap/templates/skill.md` under an existing hub | Hair-trigger `triggers`; empty `triggers` on a hub |
| **Hub / foundation / framework** | Only if a command surface is missing, or 3+ hubs re-derive the same principle | Volume for its own sake |
| **Artifact** | `05-artifacts/` or the owning project | Vault sprawl of one-off canvases |

**Graph expediency.** Prefer a reciprocal `related` + hint + route over a new
spoke. Corollary means the sibling is findable without Sean naming it. Do not
densify the graph past token value.

## When to invoke

After [[close-out]] when the gap was not only a visual detector. On session-end
if this session missed a route, broke an edge, borrowed a process, or learned a
durable pattern. On `/optimize` P0 mechanical heals. Explicit: "self-improve",
"self-healing", "connective tissue", "transfer this process."

## When NOT to use

- Honesty / over-grading failure — page Sean; do not mint a "looks good" skill.
- Archive, rename, consolidation that shrinks, new foundation/framework —
  still sign-off ([[mission-fit]]).
- Nightly cron inventing skills. Nightly folds and rebuilds; it does not research.
- Intent #17 N-agent coordination. This is single-agent vault evolution.

## Push

`personal-solo`: commit + push without waiting when the mint is calibrated
(fixture if detector) and validators are green. Report class + SHA. Never
`--no-verify`, never force-push. Page Sean only if self-critique is failing or
the mint still cannot hit the bar.
