# Critique — aesthetic + photoreal judgment

Does it *feel* authored and northstar-true under still **and** motion? Critique is judgment, not vibes-without-evidence.

## Preconditions

Native stills and/or flythrough frames available. Load #01 Aesthetic Lens, #05 Last-Mile, [[visual-qa-photoreal-rendering]], [[lead-visual-qa]]. Framework #10 enforced.

## Steps

1. **Restate the contract.** Literal / Spirit / Intent — critique against that, not against taste alone.
2. **Evidence first.** List artifacts: native still grid dims, video paths, frame indices reviewed. Refuse to critique from fit-to-window only.
3. **Still pass (grid).** Energy, material read, Fresnel at grazing, contact/shadows, atmosphere hierarchy, composition vs northstar.
4. **Motion pass (required if camera in claim).** Temporal stability, camera language vs northstar video, LOD/TAA tells, exposure continuity.
5. **Delta list.** Ranked findings: blocker / major / polish. Each finding cites frame/tile + cue violated.
6. **Verdict.** `Ready for harden-done` / `Needs craft pass` / `Needs northstar rethink`. Never "LGTM" without the triple-gate status.
