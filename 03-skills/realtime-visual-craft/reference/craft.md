# Craft — build against the contract

Implement production look/code to the locked shape. Craft without shape is thrash.

## Preconditions

- `RENDER.md` / `BUDGET.md` / `NORTHSTAR.md` exist
- Shape brief confirmed (or user supplied an equivalent locked brief)
- Pre-mortem run: load [[failure-mode-premortem]] / framework #11 for every new visible technique

## Gates (do not compress)

1. **Shape confirmed** — contract, northstar, ladder, budget, poses/paths
2. **Harden (pre)** — ledger consulted, oppositional pass, acceptance cues derived
3. **Build** — only after 1–2
4. **Evidence** — `flythrough` + `budget` + native stills before any "done" claim

## Steps

1. **Re-read contracts.** Quote the one-sentence fidelity contract and the active ladder rung.
2. **Load craft skills as needed.** [[imaging-foundations]], [[realtime-render-performance]], engine adapter, domain spokes (terrain, atmosphere, materials…).
3. **Implement the rung.** Prefer the planned approximation; do not silently jump to a costlier rung without updating `BUDGET.md` / shape.
4. **Respect absolute bans.** No energy-breaking fill lights, no post-order mistakes, no still-only "looks good."
5. **Wire measurement hooks.** Official poses/paths must be reproducible (URL params, camera booklets, harness).
6. **Stop at first evidence gate.** When the feature is visually claimable, run `flythrough` + native still capture + `budget` — do not polish on vibes.

## Build checklist

- [ ] Pass costs still fit planned envelope (or envelope updated deliberately)
- [ ] Tonemap / bloom / TAA order matches `RENDER.md`
- [ ] Depth strategy does not default to fragment log-depth
- [ ] Northstar-critical cues still targeted (not optimized away mid-craft)

## Done when (craft phase)

Code implements the shape. **Craft alone never means project-done.** Close with the triple gate via `harden` (done) after capture + measure + match/audit.
