**On the Work MBP, the Desktop is synced to the Centric OneDrive.** The employer turned on OneDrive's desktop backup, and Sean can't turn it off. The Desktop's real path is `~/Library/CloudStorage/OneDrive-CentricSoftware/Desktop/`.

- **Sean works from the Desktop for every kind of project,** personal and employer alike. A personal file there, such as a Fontface note, is expected.
- **Don't flag it as a separation breach,** and don't ask Sean to move his own files off the Desktop.
- **Agents still don't browse that OneDrive.** Read only a file Sean points to (for example with `@path`), and never search or list the rest of it.
- **Agents shouldn't choose the Desktop for personal output.** Write personal deliverables to the workspace or the project's own folder. The Desktop is Sean's to use, not an agent's default.
