# Company Docs and Figma MCP Tools

Need both human- and machine-readable docs. **Company Docs** MCP: same docs in Claude/Cursor/Slack *and* in Replit/Lovable so those tools consume *your* docs. Figma description field is the coupled-to-design slice. Console MCP **Generate Docs** tool: description + properties + specs + annotations/comments → markdown. FigmaLint first so the component is AI-ready.
