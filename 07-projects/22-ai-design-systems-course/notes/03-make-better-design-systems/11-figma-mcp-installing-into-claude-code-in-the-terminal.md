# Figma MCP - Installing Into Claude Code in the Terminal

Desktop MCP ≠ terminal Claude Code MCP. Warp/`claude --dangerously-skip-permissions` starts with **no servers**. Install via Figma’s Claude Code command (outside the session), re-open, re-auth. Selection awareness needs a **copied Figma URL**, not just “what am I on.”
