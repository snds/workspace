# Station 7: Governance & Version Control

Formal process that matches **lived reality**, plus release hygiene. Light-on: no process, or a fantasy process → support tickets, silent detachment. Missing changelog, issue/PR templates, contribution + ecosystem guidelines (recipes vs local components). Duplicate/stale issues, kinked hose. No cadence.

AI reads issues/PRs/contrib docs **and** support/comms/roadmap. Then write clearer contrib/gov docs.
