# Figma MCP - Translating Component Variant in Code Into Figma

Reverse direction: code variant → Figma (inverted variants cloned to the right of existing ones). Console MCP / write path is messy — clones can land **outside** the component set; agent hunts and restacks. Thesis: start from whichever leg is strong; pick contexts and align. One designer or one developer is enough if the stool has *something* to steal from.
