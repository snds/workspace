# Creating Design Systems

Can AI generate a DS from scratch? Technically yes. **Don’t.** Shaq: don’t do that. A DS is the story of how *this* org designs and builds. A generated kit has the same failure mode as adopting Material/Carbon wholesale: lookalike, built through someone else’s lens, no confidence it serves you.

If you have no system: pull back to problems, goals, stack, tools. AI *is* useful there — assembling context, speccing, unearthing needs. Foundations live in Brad’s Atomic Design cert course; this chapter assumes you already have a system to improve.
