# Station 2: Best Practices

Industry DS practice **and** org digital standards **and** format practice (Figma-as-Figma, WC-as-WC).

Light-on examples: Figma (no auto layout, garbage layer names, detached instances, hardcoded, messy variables, bloated files). Code (unsemantic markup, fixed layouts, magic numbers, no logical properties, overstuffed APIs, brittle JS, poor tokens). Docs that shouldn’t exist: walls of text, missing context, one-discipline skew, **no cross-links** between components and high-level a11y/i18n guidance.

AI: audit per asset and across assets; feed conventions + assessment back in to fix (e.g. rename layers).
