# Deterministic and Agentic testing with FigmaLint

Pre-AI tests still exist (unit/VRT/e2e). FigmaLint = **deterministic** (key/value presence) plus **LLM-as-judge** (subjective peer-system recommendations, e.g. size variant / icon position). Two different epistemologies in one plugin.
