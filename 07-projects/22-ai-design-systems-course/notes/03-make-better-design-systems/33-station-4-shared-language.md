# Station 4: Shared Language

Consistent **within** an asset and **across** the stool: tokens, props/values, docs, layer names, code identifiers. Most common org issue they see: `size=large` vs `size=lg`; token algorithms that don’t rhyme; docs that disagree with design/code. Root: no written naming algorithm — teams are too underwater to write it.

AI is especially good here: consistency report, then (with QA per asset) one-fell-swoop alignment across assets.
