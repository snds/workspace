# Eddie: Improving Governance with Branch Protection and PR Template

7/10. Already had issue templates, contributing, changelog. Missing: **branch protection on main** and a **PR template**. Small shop: require PR, not approvals (GitFlow — `develop` is the tank; `main` is the release cut). Require build, unit, Storybook, a11y, validation checks. PR template: why, related/closing issues, fix vs feature vs docs/chore vs breaking — not ceremony.
