# Generating documentation from Figma with Company Docs

Console MCP connected to Eventz → Generate Docs on text-area URL. Point it at `docs/components/`. Pulls house-style from sibling markdown (`input.md`). **Grounds in real code** (parity check: Figma vs TS file). Output: anatomy, properties, tokens, usage, a11y — not a free-floating essay.
