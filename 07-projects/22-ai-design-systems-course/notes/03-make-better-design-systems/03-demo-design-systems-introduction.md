# Demo Design Systems Introduction

Demos use a mix of course-only kits and real production extracts.

**Soul Patrol** (Ian) — fictitious music nonprofit. Decent DS in misalignment. Demos: tokens (incl. dark mode/rebrand), components consuming tokens vs hardcoded, products (Figma + code: donate, courses, dashboard, sharing; some React Native).

**Altitude** (TJ / Southleft) — real-ish; Figma incomplete, Storybook complete, web components.

**Eventz** — marketing, fully AI-ready, design↔code parity demos.

**College Town** — Eventz cousin, dashboards, light/dark, React Storybook.

**CBDS UI kit** — workshop: complete in Figma, purposely incomplete in React (design→code process).

**Eddie** (Brad) — bradfrost.com production DS. Web components extracted from years of enterprise work with Ian/TJ; until recently a vanilla starter. Monorepo: core WC, *recipes* (cards/headers), tokens, icons, charts, **Eddie Brain** MCP, Eddie Pages, boilerplates (Nuxt, 11ty, static HTML). Put through the wringer; now the course’s main “improve a real system” lab.
