# Agents As Users

Agents already browse, search, fill forms, buy. If the product is **illegible to machines, it is invisible to people** using those machines. Chat surfaces = your stuff inside someone else’s UI (iframe energy). DS job expands: package meaning/intention so machines wield brand, voice, UI standards **beyond the org wall**.

Kaelig’s *State of AI in Design Systems*: HTML for humans + **markdown twin** (HTML remains canon) so agents skip scrape-and-guess.

Revisit UX / UCD / UI / user stories — same words, two audiences. Produce human products *and* agent-optimized versions of the same content/services from an AI-ready DS.

**For Sean:** dual publishing (human page + agent markdown) is a concrete Centric/docs pattern, not sci-fi.
