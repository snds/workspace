# Generative UI

UI composed on the fly from user need + context: ephemeral components appear and vanish. Systems work shifts from rigid composition to **assembly + new UX categories**. DS is the constraint: blessed accessible catalog + machine-readable docs → AI maps intention → stitch in realtime. Mapping to existing components is the **speed trick** vs generating brand-new code. Flavors: compose DS components vs bespoke code vs skip the DOM into pixels. Tooling: **A2UI**, **JSON Render**. Loop: user states intention → generated UI → conversation continues, UI evolves. Pattern feels durable, not a fad. Demos next.
