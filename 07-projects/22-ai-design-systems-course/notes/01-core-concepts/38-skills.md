# Skills

Reusable instruction sets for repeatable tasks. Encode best practices, templates, domain expertise. Example: “create a proposal” that already knows brand, color, format, tone. Usually markdown + optional scripts (Python/JS).

**Turns a general-purpose model into a specialized collaborator** for menial/repetitive work.
