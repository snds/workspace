# Documentation Tools

Without the third stool leg the system falls over. Docs have always taken a back seat; still the instructions for makers *and* users (IKEA-shelf metaphor).

- **Figma:** canvas notes, property sidebar, component description. **More important now because it is context for AI.**
- **Storybook:** JSDoc-style comments auto-surfaced in the docs table → docs stay tied to code.
- Those two are siloed and role-specific, so **reference sites** exist for mixed/non-technical consumers. Zeroheight (Figma + Storybook embeds). Newer: **Mintlify** with AI in the docs process. Carbon as the canonical reference-site example (usage, style, code, a11y, do/don’t — not just props).
