# The Value of AI

AI as a **highlighter** on pain we used to treat as weather: slow/manual/repetitive work, silos, no feedback from shipped product back into process. Aggregate = expensive disrespect of people’s time.

Efficiency (faster widgets) is real and **boring**. The value they care about: broader perspective, better decisions, learning from each other, exploring possibility, **closing feedback loops** so analytics/usage actually change how the org works.

## For Sean

Same as workspace doctrine: don’t optimize the highlighter away by measuring only speed. Feedback-loop value is the interesting one — and it’s what Station 6 / context-based DS still has to prove.
