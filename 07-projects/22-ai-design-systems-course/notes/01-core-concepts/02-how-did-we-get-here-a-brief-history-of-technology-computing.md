# How did we get here?

Longer cut of the same arc already in [[01-chapter-1-introduction]]. Don't treat as new doctrine.

## Arc

Humans as social, abstract-thinking apes → communication tech → **general-purpose technologies** (Suleyman / *The Coming Wave*: steam, semiconductors; also money, writing, flight) → room-sized computers → user interfaces → home computing → the network → device explosion → machines that act autonomously.

Punchline: the job is shipping UI onto billions of connected rectangles **while keeping control**. That is why design systems exist.
