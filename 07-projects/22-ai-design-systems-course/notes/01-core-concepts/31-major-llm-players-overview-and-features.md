# Major LLM players, overview, and features

Big three: **ChatGPT/OpenAI** (mainstream chat, DALL·E), **Claude/Anthropic** (reasoning, long context, safety — *this course’s favorite*), **Gemini/Google** (Workspace/enterprise). Also: Perplexity, Grok, Meta. More alike than different — all transformers, like Chromium under browsers.

Shared: chat + (usually) API; text/code; images/files increasingly. At recording, Claude does not do photoreal image gen the way GPT/Gemini do; SVG/icons and file handling yes. Differences: personality, strengths, integrations (Claude Code/Cowork/skills/MCP vs ChatGPT’s then-smaller MCP connector set).
