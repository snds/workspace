# AI Tools Recap

| Piece | Role | Their metaphor |
|---|---|---|
| LLM | Reason + generate | Brain (Claude / Opus named as example) |
| Agents | Take action | Hands |
| Subagents | Parallelize / delegate | Split work |
| MCP | Live tools and data | USB port |
| Skills | Your specific repeatable work | Teach the collaborator |

This is “the stack that powers AI-assisted design systems work.” Later chapters compose it.
