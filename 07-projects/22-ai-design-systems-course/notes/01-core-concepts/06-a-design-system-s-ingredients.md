# A design system's ingredients

1. **UI standards** — we use these colors/type/patterns, not those.
2. **Three-legged stool** — design libraries, code libraries, documentation. Gets the attention.
3. **People + process** — how the stool is actually wielded. The part practitioners know is the real work.

Together they produce reusable UI that carries brand, UX, a11y, and frontend practice “for free.” Helsinki DS is the example: Figma components, code library, reference site — one story, three surfaces.
