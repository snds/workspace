# Subagents

Agents spawned by a parent. Parent splits the prompt, delegates, subagents work independently and report back. The multi-step checklist in spec-driven / large generated projects is usually this. Role-shaped subagents: code review, a11y, QA, fullstack, UX/UI — whichever the task needs.
