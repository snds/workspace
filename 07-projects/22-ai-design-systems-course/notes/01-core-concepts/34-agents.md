# Agents

An agent **acts**, not just replies. Early ChatGPT couldn’t touch local files/code/spreadsheets. Agents: read files, run code, search the web, call APIs. **LLM with hands.**

Example: Claude Code as an early agent platform (edit repo, tests, commits, APIs/CLIs/MCPs, machine awareness). Cursor agents similarly, with permission to edit and run CLI.
