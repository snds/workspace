# What's Hard About Design Systems?

The course’s problem statement. AI is supposed to help *these* hards, not generic “go faster.”

## Hard by ingredient

**Standards.** Living, always expanding. Gap between the ideal in the standard and product reality.

**Assets.** Quality, a11y, API inconsistency, token structure churn, uneven implementation across design / code / docs. Sync is the boss fight. Docs: nobody wants to write or read them; still load-bearing.

**People.** Mark Boulton: the design process is weird because people are weird. Politics and ROI. Team-internal relationships. Makers vs consumers with competing incentives. Shared language is hard to evangelize. People don’t read the manual.

**Process.** Adoption never finishes. Governance across a multi-layer ecosystem. Intentional vs accidental change. Versioning, breaking changes, add/modify/deprecate rollouts. Contribution programs.

Close: *through the lens of all this hard, how can AI help?*
