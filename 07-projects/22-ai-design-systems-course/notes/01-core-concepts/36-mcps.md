# MCPs

**Model Context Protocol** — Anthropic-originated standard for connecting AI tools to external data/services. USB-port analogy: universal interface. Also analogized to APIs: named tools, data in/out, errors back to the model.

Examples they’ll use: Slack, **Figma (the course’s main one)**, Google Drive, GitHub.

This is the connective tissue for the rest of the course.
