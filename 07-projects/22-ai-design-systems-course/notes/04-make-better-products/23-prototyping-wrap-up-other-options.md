# Prototyping Wrap Up & Other Options

TJ’s picks: **Lovable** when you want the full ride (logic over aesthetics). **Claude Design** for high-fid + export into Claude Code (“rebuild this with our DS”). **v0** used real components, shareable/zippable — next step is rebuild *in the real codebase*. **Bolt** beat Lovable here on DS fidelity. **Make** for speed + staying in Figma. Also: Replit (Bolt-class), Magic Patterns (custom DS, pretty prototypes).
