# Figma Make

Make kits = your DS as guidelines/rules Make can actually use. Model picker (they use Opus), plan vs build, attach a frame, connectors (they have Figma Console Cloud), custom skills. Demo uses a custom kit of Altitude tokens + component instructions. Local Make can point at real files; this run is remote.

Gen time 30s–30min depending on model/scope. Output looked like Altitude (real input, check button, image). Point: this is on-rails *if* you give it a kit, not just a prompt.
