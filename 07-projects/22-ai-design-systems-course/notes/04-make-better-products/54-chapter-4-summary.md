# Chapter 4 Summary

Four flavors: discovery (context → strategy), design (static + on-rails / off-rails prototypes), engineering (steel curtain), virtuous circle (product work strengthens the system).

**Homework:** name the flavor of every live workstream (feature / greenfield / legacy). Product-inspect a priority *and* a neglected legacy. Run an **adoption plan** on legacy. Codify a **prototyping strategy** org-wide — everyone can prototype now; the bright line is riff vs ship. Feedback loops = connective tissue for Chapter 5.
