# Prototyping With the Design System

On-rails = org UI + a11y + other standards, so there’s a **real path to production** (not “cool, now what?”). Machine-readable DS is a one-time hit; then speed matches vibe coding. More setup than ChatGPT — maybe marketers get keys, finance/HR don’t.

Double edge: this **will** expose DS holes. Broken-looking on-rails proto erodes trust; the same signal is how the system gets better. Guard who prototypes, and treat failures as intake.
