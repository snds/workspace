# AI-Generated Code & Git Commits

Brad drops the cheat-sheet screenshot into Cursor agent (Opus) and asks for a vanilla HTML/CSS/JS explainer of every Git concept, with SVG+GSAP animations and resources. It produces a whole site (index, stylesheet with custom properties, `app.js`).

GitHub Desktop then shows the **real cost**: hundreds of lines, doctype/meta churn, wiped original content, new files. Commit that as a snapshot of “the site is wildly different.”

**Point:** generation is the parlor trick; Git is how you see and accept (or reject) the blast radius. Iterate on the cramped animations next via a branch.
