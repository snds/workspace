# Publishing Repository To GitHub

Not the GitHub.com “new repo” UI. Claude Code + **GitHub CLI** (`gh auth status`, name, public/private) creates `github.com/bradfrostweb/learning-git` and pushes. Agent writes the `gh` commands; you confirm org/visibility.

`--dangerously-skip-permissions` is shown in the demo — note as their demo convenience, not a practice to copy.
