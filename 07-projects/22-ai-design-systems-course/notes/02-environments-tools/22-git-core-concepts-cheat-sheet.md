# Git Core Concepts Cheat Sheet

You don’t need every Git feature. Core set:

- **Repository** — the project folder Git manages; clone to get a hosted repo locally
- **Branch** — most important: a safe parallel timeline; main stays the live site/library
- **Commit** — snapshot with a message (“I made the buttons purple”)
- **Push / pull** — up to host / down from teammates
- **Diff** — red deleted, green added, line-oriented
- **Merge / rebase** — teams have a preferred style; ask a developer
- **Merge conflict** — two people touched the same line
- **Pull request** — “what do you think?” + reviewers
- **Issue** — the task/conversation; close it when the PR lands
