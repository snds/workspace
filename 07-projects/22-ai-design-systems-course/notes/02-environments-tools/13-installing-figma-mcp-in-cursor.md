# Installing Figma MCP in Cursor

Official Figma MCP server guide lists client-specific install. In Cursor agent marketplace: Get Figma → **OAuth** → back to Cursor. Then ask for component data by pasting a Figma URL.

**For Sean:** this is the same MCP we already use; the course treats OAuth (not PAT) as the Cursor path.
