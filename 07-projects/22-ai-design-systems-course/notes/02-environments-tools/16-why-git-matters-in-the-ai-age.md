# Why Git Matters in the AI Age

Load-bearing Ch2 lesson. AI can make a gigantic mess; Git is the sandbox: explore, refine, roll back, merge — without blowing up production.

**New handoff:** AI democratized who can write code. Git-powered workflow lets designers/BAs prototype *and* carry that work over the line, blessed by people who ship. More grown-up than vibe-coding a site in a Claude window.

**AI as mortar, operationalized:** product work files DS issues with the product’s context attached. Paper trail, visibility, cross-team connection. Merge PRs as part of ongoing work, not a separate ceremony.

**For Sean:** matches this workspace’s git discipline and Centric’s need for a safe path from prototype → DS/product repos. The “file a DS issue from product context” beat is the connective tissue they promised in Ch1.
