# Provider keys (lessons 07–10)

Walkthroughs: create a key, copy once, store in a password manager, delete the demo key.

| Provider | Where | Note |
|---|---|---|
| Claude | console → Manage/Get API key | **One key per application**, not a universal key |
| OpenAI | platform.openai.com/settings → API keys | Optional permission scopes |
| Gemini | aistudio.google.com → Get API key | Same store-safe ritual |
| Figma | Settings → Security → Generate new token | PAT + **scopes**; expiry |

Sources: `07-claude-api-keys` through `10-figma-personal-access-tokens`.
