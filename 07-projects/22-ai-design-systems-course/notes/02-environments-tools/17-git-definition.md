# Git Definition

Git = free OSS distributed VCS (~20 years), local/offline. GitHub/GitLab/Bitbucket/Azure Repos/Codeberg = hosted **source of truth** for human + agent code, plus review/collab features. Hosting is the beginning, not the whole product.
